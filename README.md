# C# Calculator

## 🇮🇷 فارسی

یک برنامه ماشین حساب ساده با رابط کاربری Windows Forms که با زبان C# توسعه داده شده است.

کاربر می‌تواند دو عدد وارد کرده و با انتخاب عملگر موردنظر، نتیجه محاسبه را مشاهده کند.

این پروژه به عنوان یک پروژه آموزشی برای تمرین برنامه‌نویسی C# و طراحی رابط کاربری ساخته شده است.

### امکانات

- جمع دو عدد
- تفریق دو عدد
- ضرب دو عدد
- تقسیم دو عدد
- پاک کردن اطلاعات
- خروج از برنامه

### تکنولوژی‌ها

- C#
- .NET 8
- Windows Forms

## 🇬🇧 English

A simple calculator application with a Windows Forms user interface, developed using C#.

Users can enter two numbers, select an arithmetic operator, and view the calculation result.

This project was created as an educational project to practice C# programming and user interface development.

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear input
- Exit application

### Technologies

- C#
- .NET 8
- Windows Forms
